# JavaClg

A collection of Java programs developed as part of my Computer Science coursework and programming practice.

## About

This repository contains Java implementations covering topics such as:

- Core Java
- Object-Oriented Programming
- Collections
- Streams and Lambda Expressions
- Data Structures and Algorithms
- Problem Solving

The programs are organized into folders based on their coursework, topics, and practice sessions.
